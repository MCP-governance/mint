# 처음 시작하기

[안내서 홈](README.md) · [다음: 직원 사용 안내](employee.md)

계정으로 로그인하고 직원 PC 키트를 설치한 뒤, 엔드포인트 활성화와 사용할 MCP를 확인합니다. MINT 로그인과 Claude Code·Codex CLI의 모델 로그인은 별도입니다.

## 1. 계정과 접속 주소 준비

관리자에게 조직의 MINT 접속 주소와 계정 또는 초대 링크를 받습니다. 서버 설치를 맡은 관리자는 [서버 설치](../../deploy/README.md)를 따릅니다.

| 상황 | 진행 방법 |
| --- | --- |
| 계정을 받음 | MINT 주소에서 아이디와 비밀번호로 로그인합니다. |
| 초대 링크를 받음 | 링크를 열어 가입을 완료합니다. 링크는 1회용이며 표시된 만료 시각 안에 사용합니다. |
| 계정이 없고 가입 요청이 제공됨 | 로그인 화면의 **가입 요청**에서 정보를 제출하고 관리자의 승인을 기다립니다. |
| 조직이 SSO를 사용함 | 로그인 화면에 표시된 조직 로그인 버튼을 사용합니다. 연결되지 않은 계정이라는 메시지가 나오면 관리자에게 계정 연결을 요청합니다. |

사설 인증서를 쓰는 조직은 관리자가 안내한 별도 경로로 인증서 지문을 대조하고 신뢰 설정을 마칩니다. 브라우저 인증서 경고가 계속되면 주소·인증서 설정을 관리자에게 확인합니다.

로컬 계정으로 로그인한 뒤에는 상단 **비밀번호 변경**에서 자신의 비밀번호를 바꿀 수 있습니다. 최고 관리자 `root`의 최초 접속과 초기 비밀번호 확인 위치는 [서버 설치 문서](../../deploy/README.md)에 있습니다.

## 2. PC 설치 모드 선택

콘솔 바로가기의 **PC 연결 설정**을 엽니다. 조직의 PC 운영 기준에 따라 모드를 선택합니다.

| 모드 | 설치 대상 | 활성화 | 적용 범위 |
| --- | --- | --- | --- |
| 간편 모드 | Windows·Linux의 현재 직원 계정 | 설치 점검을 통과하면 조직 설정에 따라 자동 또는 관리자 확인 | 게이트웨이를 지나는 호출을 판정합니다. 직원 계정의 모든 외부 통신을 격리하지는 않습니다. |
| 고급: 격리 계정 | Windows·Linux의 별도 관리 계정 | 관리자 확인 | 별도 계정과 운영체제의 제한으로 하네스를 분리합니다. |
| macOS | 별도 관리 계정 | 관리자 확인 | 시험 지원입니다. 설치·상태 확인 방법이 Windows·Linux와 다릅니다. |

Claude Code 또는 Codex CLI와 해당 모델을 이용할 계정도 준비합니다. Linux는 Ubuntu 20.04 이상, x86-64와 `/usr/bin/python3`의 Python 3.8 이상이 필요합니다. Windows는 Windows 11 x64를 지원합니다.

## 3. 운영체제별 설치 파일 실행

**PC 연결 설정**에서 운영체제를 고르고 **설치 파일 받기**를 누릅니다. 설치 파일의 출처와 게이트웨이 주소를 확인한 뒤 실행합니다.

| 운영체제 | 파일 | 실행 방법 |
| --- | --- | --- |
| Windows | `mcp-managed-setup-windows.exe` | 파일을 실행하고 UAC 확인에 응합니다. 코드 서명이 없어 게시자 경고가 나올 수 있습니다. |
| Linux | `mcp-managed-setup-linux` | 실행 권한을 부여한 뒤 터미널에서 실행합니다. 콘솔에 표시되는 명령을 사용할 수 있습니다. |
| macOS | `mcp-connect-macos.command` | 터미널에서 `/bin/bash ~/Downloads/mcp-connect-macos.command`를 실행합니다. 저장 위치가 다르면 실제 경로를 씁니다. |

설치 중 MINT 계정으로 로그인하고 필요한 관리자 권한 확인에 응합니다. macOS 연결 파일은 다운로드 후 5분 안에 실행합니다. 일회용 자격이 만료되거나 실행에 실패하면 새 파일을 받습니다.

설치 파일에 직원별 등록 토큰이 미리 들어 있지는 않습니다. 설치 과정의 로그인으로 사용자를 확인합니다. 상세한 설치 내용과 제거 방법은 [직원 PC 키트](../../endpoint-agent/README.md)를 봅니다.

## 4. 설치와 활성화 결과 확인

설치 완료와 엔드포인트 활성화 완료를 따로 확인합니다.

1. Windows·Linux는 설치가 끝난 뒤 새 터미널에서 `mint` 또는 `mint --check`를 실행합니다. Linux 격리 계정의 점검은 `sudo mint --check`를 사용합니다.
2. **활성화 대기**라면 관리자에게 PC 이름과 엔드포인트 식별자를 전달합니다. 관리자는 **엔드포인트 관리 → 엔드포인트 → 활성화**에서 처리합니다.
3. 모델 로그인을 건너뛰었다면 `mint login claude` 또는 `mint login codex`를 실행합니다.
4. Windows에서는 트레이 아이콘이나 바탕화면의 **MINT**로 로컬 화면을 열 수 있습니다. Windows·Linux 모두 `mint ui`로 엽니다.

macOS는 설치 결과의 `managed_account`를 사용해 `/Library/MCPGatewayManaged/status-<관리계정명>.txt`를 확인합니다. 관리자는 콘솔에서도 상태를 확인할 수 있습니다.

## 5. 첫 MCP 사용 확인

1. 콘솔 **도입 신청 → 사용 가능한 MCP**에서 사용할 서버를 찾습니다.
2. **이용 방법**에서 사용 목적, 제공 도구, 실행 방식과 사용 기한을 확인합니다.
3. **도구 이용 동의 → 확인 필요**에 요청이 있으면 목적·입력·외부 목적지를 읽고 동의 여부를 선택합니다.
4. 관리형 설정이 적용된 Claude Code 또는 Codex CLI에서 승인된 도구를 사용하는 업무를 요청합니다. 예를 들어 승인된 문서 검색 도구가 있다면 “승인된 문서 검색 도구로 설치 안내를 찾아줘”처럼 요청합니다.
5. **호출 기록**에서 해당 호출의 판정, 도구 실행과 응답 처리를 확인합니다.

목록에 서버가 없으면 [도입 신청](mcp-onboarding.md)을 진행합니다. 모델 응답이나 도구 호출이 실패하면 [문제 해결](troubleshooting.md)의 순서대로 확인합니다.
