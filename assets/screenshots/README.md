엔드포인트 화면에는 검색 조건을 적용해 기기 식별정보를 제외했습니다. 캡처를 위해 서버·계정·승인·정책·종료 상태를 변경하지 않았습니다. 화면의 메뉴·수치·상태값을 합성하거나 수정하지 않았습니다.

새 캡처를 추가할 때는 비밀번호·토큰·개인정보·내부 주소·업무 내용이 포함되었는지 확인합니다. 문서 이미지 보완은 제품 판본을 올리지 않고 커밋·PR로 관리합니다.
